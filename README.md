# GDT-110-Topic5-Assignment

Run the prototype by pressing the play button. The menu has a Quit button that quits the game when built and a Play button to start the game.
Upon start, use A to move left and D to move right, SPACE to jump and Left Mouse Button to fire a bullet.
Enemies will die to 2 bullet shots, increasing your score.
Touching enemies decreases your health. You will die at 0 health.
The Game Over screen has a Retry option to replay the game and a Menu option to return to the menu screen.
